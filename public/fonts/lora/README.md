# Lora

Self-hosted variable WOFF2, weights 400–600, normal/italic, Latin and Latin Extended.

Source: Google Fonts CSS API, Lora v37:
https://fonts.googleapis.com/css2?family=Lora:ital,wght@0,400..600;1,400..600&display=swap

Upstream family and license: https://github.com/google/fonts/tree/main/ofl/lora

See OFL.txt for the bundled SIL Open Font License. Interface text remains Inter,
with Space Grotesk for data headings and JetBrains Mono for technical labels.
